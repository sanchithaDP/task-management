# Task Management API

A simplified backend for managing tasks, built with **Java Spring Boot**, following **Domain-Driven Design (DDD)**, **Test-Driven Development (TDD)**, and clean coding principles.

## Features
- Create, retrieve, update, delete tasks
- List tasks sorted by due date
- Validation for mandatory fields and future due dates
- In-memory repository (no database required)

## Bonus
- Pagination & filtering by status
- Future date validation

## Requirements
- Java 17+
- Maven

## Run
```bash
mvn spring-boot:run
